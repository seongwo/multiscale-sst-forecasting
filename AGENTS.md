# Repository Guidance

This repository is a cleanup copy prepared for public release.

- Preserve the existing `model/`, `model/models/`, `model/modules/`, and `model_train/` layout.
- Do not rewrite model logic during cleanup.
- Do not commit raw data, checkpoints, prediction arrays, logs, Python caches, or generated sample images.
- Keep notebooks output-cleared unless a small static output is intentionally required for documentation.
- Treat `configs.py` as requiring manual review because it may be auto-generated by ablation runners.

Use import checks, dummy model forward passes, and loss/metric tests. Do not run full training during repository cleanup.
